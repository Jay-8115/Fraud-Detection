====================================================
PROJECT OVERVIEW
====================================================

The application allows financial analysts to upload transaction datasets in CSV, Excel, or PDF format.

The uploaded file is automatically processed.

The ML model predicts fraudulent transactions.

The system generates visualizations.

Generative AI explains the results in simple business language.

The user can download a detailed professional PDF report.

All analysis history is stored.

Admin can monitor all users and analyses.
